# MoonLetter V44 — 换张小纸，留句话

版本：`0.1.0+note-stationery-v44-20261026`，versionCode 44。

## 便签

- 三种纸样：贴贴、横线、信笺；五种纸色：奶油、淡桃、嫩叶、雾蓝、浅紫。
- 写便签时点「换张纸」，直接预览和选择；不增加标题、照片或发布步骤。
- 时间轴纸张更轻，减少折角、阴影和装饰留白；详情沿用同一纸样。
- 纸样随便签同步；未发出的文字、隐私选项和纸样一起暂存。仍复用原有事务、重试和权限链路。

已有无纸样数据的便签采用默认奶油贴纸；不重写历史内容。旧客户端仍能阅读正文。颜色不再代表作者，作者名称保持独立。

## 更新顺序

这版需要一次服务端兼容更新，保留原数据库 schema 16。旧服务端会忽略纸样字段，因此先更新服务端，再在两端覆盖安装 V44。不要卸载、清数据或重新配对。

服务端更新包：`moonletter-note-stationery-v44-20261026.tar`，只含新 JAR、其校验文件和更新脚本，不含任何密钥、配置、记录或媒体。更新脚本先执行既有备份与恢复校验，保存旧 JAR；不修改 .env、OSS、HTTPS 和数据库结构。

在自己的 Windows PowerShell（不是服务器终端）上传，将 `YOUR_ECS_IP` 换为服务器公网 IP：

```powershell
scp "E:\MoonLetter\Moon-Letter\releases\v44\moonletter-note-stationery-v44-20261026.tar" root@YOUR_ECS_IP:/root/
```

然后在服务器 SSH 终端：

```sh
tar -xf /root/moonletter-note-stationery-v44-20261026.tar -C /opt/moonletter
sh /opt/moonletter/update-private-app-v44.sh
```

脚本遇到问题会停止应用并保留原 JAR 和数据；不要用无关旧版本回退。健康检查通过后，再在两台设备覆盖安装 `MoonLetter-note-stationery-v44-20261026.apk`。

## 验收

1. 写一句话→换纸样、换纸色→贴进手账；时间轴和详情一致。
2. 退出后重进未发送便签，文字和纸样保留；完整编辑器草稿不变。
3. 另一端同步后看到同样的纸样和正文；隐私便签仍按原规则隔离。
4. 键盘展开、横屏和平板仍能选择和发送；旧便签仍可阅读、回应。
