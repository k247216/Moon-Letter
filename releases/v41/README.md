# MoonLetter V41 — 纸页小细节

版本：`0.1.0+paper-details-v41-20261014`，versionCode 41。
交付日期：2026-10-15。

## 本轮范围

- 小书签改成轻量纸页抽屉，显示日期、标题、两行正文片段和自然比例小照片；用书签按钮取消标记。点纸页仍打开原记录，不生成副本，不显示无权限的记录，不删除内容。书签仍是各自设备的个人标记。
- 音乐添加改成播放链接优先，歌曲名称和歌手作为补充；也允许只留下歌名。阅读采用小唱片便签，只有有效 HTTP(S) 链接才显示打开按钮；不抓取音乐、不伪造歌曲信息、不新增内置播放器。
- 音乐弹窗开关及未提交的歌名、歌手、链接可随界面重建恢复，不会在恢复时自动加入记录。
- 随机翻城市仍随机选择有故事的城市；显式选择、搜索或随机切换后，故事列表从最新回忆开始。城市代表卡优先最新记录的标题、正文和自身照片，不借旧照片冒充最新回忆。

不改数据库结构、不清空记录或媒体，不调整 V40 的图片缓存、草稿状态机和云端存储。本轮不需要部署服务器。
