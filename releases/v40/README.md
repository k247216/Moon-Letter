直接覆盖安装 `MoonLetter-personal-keepsakes-v40-20261013.apk`。保持原签名；不要卸载、清除数据或重新配对。本轮仅更新 Android 客户端，不需要更新服务器，也不需要按顺序安装旧包。

## 本轮改动

- 时间轴图片复用已有本机原图和缓存；上传确认、云端路径变化不再仅因缓存键变化重新显示加载状态。增加本地派生预览磁盘缓存，保留图片自然比例、原图字节和已有展示样式。
- 纪念日保留一个紧凑入口，移除重复的大块入口；原有日期、提醒与卡片数据保留。
- 意外退出编辑可从“记录”继续当前内容；主动“存为草稿”后，下次新建为空白页，旧内容仍在草稿箱。旧草稿不猜测为未完成编辑。
- 详情页可夹上或取下轻量小书签，时间轴可快速翻回这些记录。书签为当前设备、当前身份的个人标记，不删除记录，也不声称已跨设备同步；隐藏或删除的内容不会由书签重新展示。
- 语音可填写短标题，随现有记录与草稿保存，并在时间轴、详情和回忆手书中展示；不改变音频原件和播放链路。
- 修复连接身份版本刷新时序，保留旧请求失效保护和身份隔离。

不改云端数据库结构，不清理既有数据。不新增完整收藏夹、时间检索或内容搜索。
