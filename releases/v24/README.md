# V24：地图标记与手账时间轴

版本：`0.1.0+journal-map-v24-20261004`，versionCode 24。

## 验收入口

- 地图不再为城市标签另画第二个圆点。真实坐标处只保留一个标记：普通城市淡灰点，有故事的城市暖色点，当前选择额外加细圈。故事与选择是两个独立状态。
- 全国、区域、详细三级显示；区域层提前显示湖州、绍兴、绵阳、宜昌等已有地级市。没有伪造新坐标或增加虚假到访数据，详细层使用现有数百座城市目录。
- 保留上次浏览城市、最近故事默认城市、全国概览、城市封面卡、首次/最近日期和随机回看。投影坐标缓存，街道地图避免重复发送相同标记数据。
- `我们 → 设置 → 回忆数据` 查看有故事的城市数、省级地区数和城市记录数。地图和个人页首页不放累计统计；数据不代表实际到访。
- 时间轴未读记录使用淡色小信封，保留无障碍描述；快捷入口为“看看这封小笺”。左侧连续弯曲缝线及记录之间的手绘弧线替代弱直线。阅读进度仍是本机状态，不是向对方发送已读回执。
- 保留自然比例照片墙、相册集封面、媒体云端链路、草稿和离线回忆手书。

本轮无需服务器更新。覆盖安装，不卸载、不清数据、不重新配对。公网 HTTPS 与备案状态不因本次 UI 更新改变。
