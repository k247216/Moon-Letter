# 月笺 V38：日常阅读打磨

本轮不增加功能，不改服务端、数据库结构、同步接口、隐私规则或原媒体文件。

## 使用者能感受到的变化

- 翻到旧记录，进入详情后返回，时间轴保留原来的浏览位置；切换底部页面、打开编辑页或草稿箱后回来也可以继续阅读。浏览位置按当前服务来源、空间和身份分开。
- 已加载且仍在内存缓存中的照片，重新进入页面直接显示；不必先出现空占位再异步读取缓存。
- 列表预览与高清阅读图各使用独立的 8 MiB 图片缓存，按实际图片占用字节淘汰。不再简单地只留八张，也不让少数高清图片挤掉列表的小预览。
- 原图下载和保存不变，照片自然比例、照片墙拼图、相册封面及手账布局不变。
- 即时缓存仍在后台校验；本地来源失效时清除旧画面，原图暂时下载失败时保留有效预览。

## 安装与限制

仅客户端更新；不需要服务器更新、不需要重新配对。覆盖安装，不卸载或清除数据。

当前没有连接真实手机或平板。自动化阅读测试不能证明真机滑动帧率或异地网络延迟；这轮只修复已复现的缓存与返回位置问题，不声称解决所有卡顿。
