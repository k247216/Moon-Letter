# MoonLetter V42 — 通知可靠性

版本：`0.1.0+quiet-notices-v42-20261022`，versionCode 42。

## 本轮范围

- 保持时间轴的外观和提示不变，仅优化系统通知栏与点击跳转。
- 新记录和对方回应分开通知，通知不包含记录标题、正文或回复内容。每类更新替换同类通知，避免堆积。
- 首次读取已有内容安静建立基线，之后新增记录再提醒；编辑旧记录、删除、对方暂时隐藏的记录及其他空间的数据不算新到达。
- 系统权限或通知通道关闭时不提前记为已提醒；恢复后，下次同步可重新尝试。
- 每次成功的文字同步独立处理新提醒，不等待其他正在进行的网络刷新。
- 通知点击校验服务器、空间和成员；无身份范围的旧通知只打开应用，不自动跳入内容。纪念日、心意卡、胶囊提醒进入对应功能。
- 正在写记录时不丢弃编辑器；通知导航等待当前编辑退出后处理。同一记录后续回应的再次点击可重新打开记录。
- 晚到数天的心意卡任务不再声称“今天”；胶囊继续要求服务端确认可以拆封，不放宽隐私权限。

不修改数据库结构，不清除记录、图片、草稿、身份或待上传内容；不调整既有图片缓存、时间轴样式及书签。本轮不需要部署服务器。

## 安装与验收

直接覆盖安装，不卸载、不清数据、不重新配对。建议两台设备均更新。

验收：首次启动不刷历史提醒；对方新写记录和发表评论后检查通知栏；关闭通知权限后新增内容，恢复权限并等待下一次同步；通知点击到正确记录或提醒功能；写记录时收到通知不丢输入。

本版没有接入小米／vivo 厂商离线推送。前台同步和后台任务仍受网络、系统省电与进程存活限制，不能保证杀进程后的实时通知，也不保证定时提醒精确到分钟。实际双机送达仍需真机验收。
