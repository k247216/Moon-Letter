# V35 · 回忆手书与双视角

本轮仅更新 Android 客户端，不需要上传服务器包，不更改服务端接口、数据库结构或 OSS 目录。

## 安装原则

使用本目录 APK **覆盖安装**，不要卸载、清数据或重新配对。沿用现有包名与签名。
两台设备都更新后，才能同时看到新的创作与阅读样式。

## 验收路径

### 回忆手书

“我们” → “回忆手书” → “回忆手书”：

- 按周或按月选择时段，横向滑动或使用上一页/下一页翻阅。
- 一篇真实记录是一页；正文完整保留，照片、录音、视频、音乐与地点按原顺序呈现。
- 照片先使用轻量预览，点开才请求原图；不改变保存原图、相册照片墙或导出原件。
- “读完整这一页”进入原记录和回应，返回后保留所选时段与翻阅位置。
- “过去的今天”只展示更早年份同月同日的真实记录；没有同日历史时可以进入其他日子的手书。

### 双视角

“＋记录” → “共同记录”：

- 标题及故事发生时间共同使用；两位作者各自署名。
- 第一位保存后，另一位进入该记录，使用“补写我的视角”。
- 补写参考已有文字及媒体，不把参考块重新提交；只能提交本次自己的新内容。
- 作者由稳定身份区分；同昵称、图片/语音贡献、再次补写不会合并署名或改变原内容顺序。
- 两人已有正文只是落笔情况，不是假在线状态、共同确认或对方已收到的承诺。
- 完整阅读以共同手账呈现，回应仍在正文下方，原有评论发送链路不变。

## 数据保护

- 当前空间内的已发布、未删除记录才进入回看；暂时私密记录仅本人可见，草稿和未拆封胶囊不混入。
- 原记录、相册、原图、录音/视频原件、身份、同步队列、备份与导出格式不迁移、不清理。
- 补写草稿增加来源/空间/成员隔离，切换身份时保存最后输入到旧成员的槽位。
- 极早期无作者归属的补写草稿文件保留在本机，但不能安全判定属于谁，因此不自动展示给当前登录成员；不会删除其文件或附件。
- 撤回最后参考块不回显旧正文；回看里撤回照片会关闭它的查看器。
