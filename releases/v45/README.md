# MoonLetter V45 — 纸条留在手账里

版本：`0.1.0+journal-notes-v45-20261026`，versionCode 45。

## 这轮的取舍

采用轻手账拼贴与极简纸片的结合：优先让纸条与时间线发生关系，保留安静的奶油底色和原有字体，不增加贴纸素材库或新的选择步骤。

- **时间轴：** 按实际换行测量短句宽度，短句收成靠近时间线的小纸条；自然高度，无固定大留白。较长内容预览五行，轻点进入全文。作者、时间、私密与未读标识放在纸外。
- **纸张：** 短贴纸有轻微撕边，其余纸样保持平整克制；阴影减弱，细微纸纤维在静态绘制中缓存。每张纸至多一个小附件，胶带可在左／右上角，也可能是小图钉或留白。位置由记录 ID 稳定决定，不随刷新或设备变化，不旋转正文，不运行动画。
- **详情：** 便签只在顶部显示一次日期，正文纸片和落款成为主角。回应改成更淡的小纸片，保留时间顺序、作者和输入发送行为。普通图文、音乐、语音等记录详情布局不变。
- **归属：** 纸色由作者选择；签名色按两位成员身份固定，双方查看同一个人时颜色一致。映射复用已有成员资料刷新，在本机按服务器与空间隔离缓存。资料尚未取得时沿用原来的我／对方颜色，不伪造身份。

V44 的三种纸样与五种颜色继续保留。对历史记录不做内容、隐私或纸样重写；本轮不修改数据库、同步队列格式或云端接口。
