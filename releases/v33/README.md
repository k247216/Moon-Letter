本版不清数据、不换空间、不重新配对；沿用原 APK 签名覆盖安装。先更新服务器，再更新双方应用。

## 变化

- 手书照片预览与字体嵌入离线网页；自然比例照片、纸张相框、手写排版、回应页和轻微呼吸动画。减少动画偏好与打印模式关闭动画。
- 原照片、声音、视频仍按原字节放入 ZIP，附 SHA-256 与大小；缺失原文件、损坏照片不会假装导出成功。
- 单独「记录数据存档」：记录 JSON、原媒体和校验清单。明确只含这台设备可读取的已发布记录，包括自己的暂时隐藏记录；不含独立相册、草稿、未解锁胶囊，不是云端全量备份，也没有应用内导入。
- 导出使用同一事务快照，过滤私有路径/凭据元数据，拒绝非媒体目录路径；取消和空间切换清理未交付文件。
- 同一记录不会越过前序待上传、退避或被拒绝的操作；永久 4xx 停放，临时网络失败继续重试。切换/取消后不继续提交旧响应。
- 换机码只恢复签发者自己，不能获得另一位成员身份；V16 撤销旧未使用换机码，不影响已登录设备或正常邀请。
- 删除块的正文/媒体引用不再通过旧同步快照重新下发；追加媒体须 READY 且类型/空间正确；头像须自己的 READY 图片。
- 服务端全部导出不再遗漏过去或未来日期，错误日期与反向范围按输入错误处理。
