# MoonLetter V43 — 小便签与纸面交互

版本：`0.1.0+paper-interactions-v43-20261025`，versionCode43。

## 这次改了什么

本轮合并文字按钮的局部按压反馈、日期／时间惯性滚轮、日历切换、时间轴轻纸面与曲线细线、可选相册级分类。记录时间仍按原时区保存，纪念日／卡片／胶囊和提醒规则不改；滚轮停稳再确认，多列不互相覆盖，旋转保留未确认选择。相册不填分类时归入「未分类」，不新增照片级标签。不做强制列表吸附。

首页「记下今天」现在打开独立的纯文字便签，无标题、照片、工具栏和模式选择。正文最多500 Unicode码点，空白不能发布，不要求写满。完整记录仍从底部「＋记录」进入，原有草稿、图片缓存、通知及其他功能不改。

便签使用暖奶油纸色、半透明胶带、小折角和原手账字体；手机与平板居中限宽。打开时纸张轻轻舒展，本机保存成功后短暂贴好反馈。时间轴使用紧凑纸签，点开后可读全文和回应；滚动中的纸签没有循环动画。

未发出的文字在本机按服务器/空间/成员隔离暂存，返回或重开继续；不会占用完整编辑器的草稿槽。共享便签离线先写入现有Room事务及同步队列，不等网络才退出；保存成功不等于对方已收到。隐私小开关沿用「给我们看／先收在心里」，私密能力校验失败不会降级公开。

## 数据与兼容

不改数据库结构，不清空任何记录、草稿、媒体或身份，不需要部署服务器。便签采用既有PERSONAL+TEXT格式和系统标题「小便签」，旧客户端也能读取正文。普通同名无媒体记录会采用便签外观，内容与权限不变。导出仍包含真实文字，不制造额外副本。

稳定ID避免重复提交；恢复时核对Room，已提交的临时文字不反复出现，较新的文字获得新ID，不会被旧提交清空，也不复活已删除的旧记录。

直接覆盖安装，不卸载、不清数据、不重新配对。建议两端更新以显示一致的便签外观。

## 建议验收

1. 首页记下今天→直接写一句→贴进手账；底部＋记录仍是完整编辑器。
2. 写一半返回再进入，文字仍在；完整记录的旧草稿不受影响。
3. 断网贴一张，恢复网络后另一端能看到、点开并回应。
4. 先收在心里的便签对方暂时不可见，既有详情隐私操作仍可使用。
5. 键盘打开时底部按钮可点击；平板、横屏和大字号布局不溢出。
