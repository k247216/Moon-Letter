# V32 · 视频、时光信箱与隐私控制

先更新服务器，再给两台设备覆盖安装 APK；不卸载、不清数据、不重新配对。默认封面及既有记录、相册不变。

- 视频：点击播放，鉴权下载原件，独立播放器支持暂停和拖动；区分下载失败与格式不支持，可重试。未转码原文件，具体设备编码兼容性仍须真机验收。
- 时光信箱：独立云端保存，两端读取同一份信件；对方到开启日期前只能看信封，服务端不返回正文。可仅自己保留；旧本机信件需本人确认后导入，默认私密。
- 个人记录：保存时选择“给我们看”或“先收在心里”，详情可修改范围。私密也在云端保存，仅作者可读。隐藏后对方下次同步撤下本机投影；已保存到相册或导出的副本不能远程收回。共同记录保持共享。
- 纪念日、生日及惊喜卡：共享日期两人可看、可逐年编辑；私密小计划只提醒本人。系统权限、省电限制及网络会影响后台提醒，不能承诺关闭应用后的即时送达。

## 服务器更新

将更新包从 Windows 传到服务器，再在服务器执行：

Windows PowerShell：

```powershell
scp "E:\MoonLetter\Moon-Letter\infra\local-runtime\cloud-transfer\moonletter-private-keepsakes-v32-20261010.tar" root@192.0.2.10:/root/
```

服务器终端：

```sh
tar -xf /root/moonletter-private-keepsakes-v32-20261010.tar -C /opt/moonletter
sh /opt/moonletter/update-private-app-v32.sh
```

包内不含密钥、`.env`、重置脚本。更新先备份并验证隔离恢复；只替换 app，不改变 Caddy、OSS 或端口。

**数据库将升级至 15。隐私迁移后不能直接换回旧服务端 JAR**，旧版不识别隐私字段，可能暴露私密记录。失败时脚本会安全停止新服务，而非在已迁移数据库上自动运行旧版；须诊断或明确恢复已验证的完整备份。不要执行旧版本更新脚本。

## 双端验收

1. 双方分别使用移动网络或不同 Wi-Fi；确认原记录、草稿、身份仍在。
2. 上传可播放的 MP4，另一端点开播放、暂停、拖动，再测试离开返回及失败重试。
3. 私密记录只在自己设备可见；共享后对方出现，隐藏后对方下次同步撤下；自己的重启/云端恢复仍保留。
4. 时光信箱未来日期不显示正文；改为今天后对方能读；私密信件对方列表中没有。
5. 共享生日/纪念日两端一致；私密惊喜仅自己可见并收到提醒；删除或隐藏后不再提醒对方。

本地自动测试及打包不等于线上部署或真机验收完成。
