# V37 · 回看、重要日子与草稿续写

仅更新客户端，服务器无需更新。覆盖安装，不卸载、清数据或重新配对。

## 本轮修复

1. “过去的今天”进入独立同日历史页；探索其他日子通过明确路由进入回忆册，不污染同日入口的保存状态。无同日历史保持空态，不能伪造去年回忆。
2. “我们”页重要日子摘要改用云端卡片中最近的共享生日/纪念日，和点击后的卡片库一致；空态为“留住重要的日子”，不把旧缓存空误报成没有纪念日。私密计划/惊喜不进入此摘要；提醒调度和送出前云端确认继续保留。
3. 点击新建或“记下今天”恢复当前成员、当前类型最近的未完成草稿，沿用同一槽位及文字、照片、附件、发生日期和可见范围；草稿箱提供“另写一篇 / 新的共同记录”。来自其他应用的分享始终创建独立槽位，切换前立即保存旧编辑器最新输入，不依赖防抖或 ON_STOP。已发布草稿仍按原规则移除。
4. “每周回看”说明为“每周旧笺提醒”：每周重看一篇至少八天前的记录，没有符合条件的旧记录就不通知。它不是周报、统计或另一种手书。WorkManager 仍只保证调度窗口，不保证精确分钟。
5. 时间轴内容块按记录一次分组，避免每篇记录重新扫描全部块；在投影前去除内容相同的 Room 发射。排序、日期、正文/媒体和既有 Default 后台处理保持不变。100 篇/200 块测试验证内容块遍历保持线性，未把它当作真机 FPS 证据。

## 验收

- 过去的今天 → 探索其他日子 → 关闭 → 再开过去的今天，保持正确的同日历史/空态。
- 创建生日/纪念日后返回“我们”，最近日期摘要与卡片库一致；私密计划不进入共享摘要。
- 编写文字、照片和私密范围，横屏中断后点新建，应接回未完成草稿；继续发布，不新增重复草稿。
- 草稿箱“另写一篇”不会覆盖旧稿；普通草稿与共同记录草稿互不混用。
- 测试时间轴连续滚动与同步更新；实际帧率、自动横屏行为仍需要真机验收。本轮不锁死手机/平板横屏，也不声称旋转时编辑器不重建。
