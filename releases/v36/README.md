# V36 · 回忆册视觉打磨

仅更新 Android 客户端，不更新服务端，不迁移、删除或复制正式数据。

## 设计

- 专门的应用内回忆册，不复用离线导出 HTML。
- 横向翻阅时轻柔倾转与缩放；并非模拟复杂纸张卷曲，也不使用循环动画。
- 纸页叠层、柔和阴影、日期印章、手绘曲线与小爱心。
- 回忆照片使用细相框与贴角；Fit 完整展示，不旋转照片、不裁切原图。相册照片墙与相册集不改变。
- 文字边缘使用双方不同的淡色线条，保留现有字体与阅读对比度。
- 内容顺序、作者、周/月选择、原记录跳转、媒体播放及回应保持 V35 逻辑。

同步、备份、导出、原媒体与权限投影不变；V35 补写草稿隔离保护继续保留。
