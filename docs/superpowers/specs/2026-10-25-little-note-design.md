# 纯文字小便签

已确认：用户要求将首页「记下今天」从完整编辑器改为独立纯文字便签；可爱、统一、设计感和轻动效，低负担。完整记录入口保留。

采用暖奶油纸、半透明胶带、小折角，正文沿用手账字体。单页直接写，无标题、媒体、模式选择。上限500 Unicode码点，空白不可发布。小隐私开关默认共享，沿用先收在心里的权限语义。返回/后台立即保存本机临时文字，独立于完整记录草稿；提交失败保留，提交成功后清理相同版本草稿。编辑时禁止重复提交。

动效：单次纸张舒展，成功本机事务后短暂盖章/贴好反馈；不假称云端送达，不等待联网，不在滚动列表运行无限动效。尊重系统动画时长设置。键盘与系统栏正确避让；平板居中限宽；大字号可滚动。

方案：新增服务端类型会增加升级和迁移；仅换编辑页不能提供便签阅读。选择现有PERSONAL记录+系统标题「小便签」+单个TEXT块。客户端仅将这种无媒体的记录识别为便签，普通同名纯文字记录也会采用便签外观（不改内容/权限）。旧客户端仍能正常读，服务端不改，JSON/手书导出保留真实正文。

权限：本机临时便签按服务器/空间/用户隔离；发布只使用打开时捕获的绑定，切换绑定不得误投新空间。共享便签离线保存入已有事务outbox；私密便签须先确认现有服务端隐私能力，失败不降级公开。

范围外：滚轮、相册标签、其他时间轴结构、提醒、云端结构、旧草稿状态机。用户已授权执行，不重复设计确认。
