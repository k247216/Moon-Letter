# 月笺 UI 重构设计

## 目标

把当前“功能入口存在但像半成品”的 Android 界面重构成一个用户愿意每天打开的情侣记忆空间：用户第一眼感到这是两个人共同生活的纸上档案，写记录时感到是在写信，回看时能快速找到人、时间和情绪。

## 视觉基准

以 `docs/design/reference/` 中的六张指导图为唯一视觉方向：

- 首页是带月色封面的连续纸面时间轴，不是卡片列表。
- 编辑器是留白充足的书写页，标题、时间、作者和附件有编辑感。
- “我们”页先讲关系，再承载设置；相册和城市页先展示记忆，再展示工具。
- 主色为纸张暖米色、珊瑚色、鼠尾草绿和墨色；手绘下划线、缝线、胶带和拍立得只作为结构线索，不做装饰堆叠。

## 交互原则

1. 首屏必须在 3 秒内回答“我们是谁、最近发生了什么、下一步能写什么”。
2. 新建记录是全局主行动；保存状态必须显眼且诚实区分“本机已保存”和“已同步”。
3. 时间轴整条记录可点，内容预览、作者、时间、照片和同步状态要在一个阅读单元内完成理解。
4. 任何暂未接通的能力必须使用明确的占位状态，不提供看起来可用但没有结果的控件。
5. 不改变 Room、同步、配对、媒体资产和现有服务端接口的语义；UI 只消费现有状态和回调。

## 页面重构范围

### 设计系统

建立共享的纸面 Scaffold、章节标题、手绘下划线、缝线时间线、拍立得照片、头像组、状态标签和编辑工具栏；底栏使用正确的五个图标和统一的选中态。

### 时光首页

封面作为首屏视觉入口；正文使用日期章节和左侧缝线，记录取消通用卡片壳，改为开放式纸面阅读单元；照片使用轻微错位的拍立得样式；空状态只保留一个明确的“写下第一句”行动。

### 编辑器

重做个人记录和共同记录的顶部层级、标题和正文输入、作者状态、发生时间、附件工具栏与保存 CTA。正文优先，工具不抢焦点；共同记录明确展示双方视角和当前可编辑位置。

### 我们、相册、城市

“我们”页使用关系 Hero、头像与相伴天数、纪念日入口和分组工具；相册使用月份章节和照片网格；城市页使用地图/地点概览与故事列表。保留现有入口回调和数据投影。

## 非目标

- 本轮不新增后端接口、不改数据库 schema、不重写同步协议。
- 本轮不把指导图直接做成不可交互的背景图。
- 本轮不保证未接通的语音、视频、音乐能力变成真实上传能力；只改善其诚实的入口和状态反馈。

## 验收标准

- `390×844` 下首页、编辑器、“我们”页的主要 CTA 和底栏不被遮挡。
- 首页、编辑器、“我们”页和相册/城市页都使用同一套纸面色彩、字体层级和间距语义。
- Compose 屏幕测试覆盖底栏导航、首页空状态、新建记录入口、编辑器保存状态和工具页返回入口。
- `:app:assembleDebug`、Android JVM 测试和现有服务端回归测试通过。
