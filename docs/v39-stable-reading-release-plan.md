## 发布门槛

1. 图片：列表轻预览与 1200 阅读预览分档；原件下载保存不改。自然比例与安全高度上限并存；后台校验失效来源；服务/空间/身份缓存隔离；可见图额外占用不冒称缓存预算就是总内存。
2. 启动：封面/头像异步、限尺寸解码；第一帧只等待本机首批时间线及装饰图，最多 1000ms，不等网络，不无限阻塞。
3. 纪念日：共同空间确认日期与本机草稿分离；原始年份必须明确选择；公历每年重复；提醒时间仅本机。生日/心意卡入口仍独立。中秋农历换算本轮延期，不以固定公历日代替。
4. 写入和提醒：取消、ABA、旧 GET/新 PUT 交错、写盘失败不得冒充确认；离线恢复已确认提醒；设备关闭提醒、跨日过期任务、旧账号任务均不能错误通知。
5. 验证：先运行可编译的实际失败测试，再修复；完整后端/Android 回归、构建、签名与哈希、合成原生手机/平板截图检查；独立代码复查的重要问题闭环。
6. 更新：后端先更新，再双方覆盖安装客户端。服务器更新核验 schema16、备份并恢复验证、保留原 JAR；不重置、清数据、重新配对或改公网端口。

## 不可冒称的验收

本机自动化测试不代表真机帧率、真实异地网络延迟、Doze 下精确通知时间或已完成线上部署。已有数据库/OSS保护不受本轮改动，不等于宣称完成新的云端恢复演练。
