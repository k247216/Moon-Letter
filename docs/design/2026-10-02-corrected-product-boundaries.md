# 本轮重构：以指导图和实际用途为准

用户要求自主连续实施，不再逐功能确认。下面记录实施约束，不代表已经验收。

## 页面结构

- 首页：单一半屏封面，左上短句、右下换图；删掉重复标题和宣传文字。日期章节左对齐，左侧缝线连续，图文相邻、照片位于正文右侧，音乐和城市有独立内容层级。不能用同步状态充当正文。
- 相册：独立相册和照片表。新建相册填写名称/分类，进入相册通过系统选择器添加照片，私有目录保存照片，月份拼贴和全屏查看。不创建记录、不写入记录上传队列；云盘连接后续再做，不能显示已上云。
- 地图：真实地理底图是主体，支持拖动、缩放、地图点选城市；城市名称不是替代地图的标签列表。点选仅切换城市，不生成空地点记录；所选城市下只显示其随记/照片，写故事进入带城市的正常编辑器。不申请定位权限。
- 编辑器：个人/共同模式复用同一顶栏、正文、附件和等宽工具栏。去掉无功能的“更多”。关闭可保留草稿，完成保存记录，城市入口使用地图选择器。
- 主导航：五个等宽48dp以上点击区域，同一图标槽与文字基线，中间加号只在槽内视觉抬起，不能撑高自己的文字。

## 验证与限制

数据库升级必须保留旧记录，验证相册持久化及与记录隔离；地图过滤与城市坐标测试；Android编译及APK版本/hash检查。现已建立 Android 14 / API 34 Pixel 6 模拟器，原生测试和截图见 `docs/testing/visual-v7/`；模拟器证据不代替两台实体手机的互见验收。第三方底图可用性和上线授权必须写清；不新开云服务器、不购买服务、不上传私人照片。

执行裁定：新建相册必须独立，覆盖此前“复用共享记录承载相册照片”的旧方案。默认离线地图使用 DataV 省界和真实城市坐标；街道底图仅在用户明确切换后联网加载，不申请定位。云盘接入后续实施，当前页面必须明确保存在本机。当前工作区包含既有未提交改动，不切换或清理工作区，不提交、不推送。
