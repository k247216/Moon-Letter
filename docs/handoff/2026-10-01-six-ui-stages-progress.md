# 月笺六阶段客户端推进快照

更新时间：2026-10-01
当前分支：`m1-stable-recording-loop`

这份快照把“这台机器能继续做什么”一次列清楚。Compose、客户端路由、本机草稿/Room 投影、视觉文案和交接文档由本机推进；服务端 API、SDK、Gradle、模拟器、真机和双端同步证据由另一台机器完成。

| 阶段 | 本机已落地 | 仍需 SDK/真机证据 |
| --- | --- | --- |
| 1. 指导图核心壳层 | 连续时间轴、左侧缝线、五栏导航、头像/名字/封面/主题 | 390×844 逐屏截图、安装包版本确认 |
| 2. 记录与详情 | 个人/共同编辑、草稿自动保存、状态反馈、整卡详情、评论、城市/音乐详情块 | 双视角版本快照和越权编辑的服务端闭环 |
| 3. 相册与地图 | Room 媒体月分组、媒体回源、城市故事列表、手动城市快照、离线保存状态 | 视频/语音上传、LOCATION DTO、双端投影、真机地图权限 |
| 4. 时间与回看 | 中秋纪念日 ISO 日期本机倒计时预览、胶囊锁定元数据、过去的今天、本周小结、通知设置 | 农历/服务端倒计时、胶囊到期解锁、真机通知时点 |
| 5. 分享与导出 | 系统文字/图片分享直达草稿；本机导出 Markdown + JSON；头像/名字/主题/封面入口；设置图标有明确说明 | ZIP + 原始媒体、网易云 MUSIC block、跨端资料同步 |
| 6. 验收与交接 | 每轮独立 commit、验收记录、真实边界文案和本机静态检查 | SDK 构建、安装、双机录像、视觉对照和最终 Gate |

本机不把“等待接口”画成成功，也不运行 Gradle/Android SDK/模拟器；所有未验证项都保留在 `docs/testing/m1-acceptance.md`。
