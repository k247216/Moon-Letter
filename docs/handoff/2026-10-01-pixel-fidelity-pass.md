# 月笺视觉对齐记录（2026-10-01）

## 本轮目标

以 `docs/design/reference/` 的六张指导图为视觉基准，先修正跨页面共用的骨架，再补相册、地图、编辑器和「我们」页的可用入口。本机只做源码与静态审阅，不运行 Android SDK、Gradle、模拟器或服务端。

## 已落地

- 统一暖米色、珊瑚橙、鼠尾草绿、纸张线条和底部导航色板。
- 底部导航改为参考图的浅紫色导航栏；中间「＋记录」为凸起珊瑚圆形主操作，其他 tab 用图标+文字表达选中态。
- 时光页默认使用封面资源，增加参考图式标题层、换图入口、按日期分组和连续手帐节点；记录卡仍保留点击打开详情的可用性。
- 相册增加「全部 / 照片 / 视频」筛选，并改为更接近参考图的三列缩略图布局；媒体仍回到原记录打开，不复制第二份数据。
- 地图页将城市快照限制保持为一次主动记录，并把城市路线、节点和故事列表放在同一屏内；无快照时仍能解释空态。
- 编辑器与共享编辑器使用同一纸张/导航色板，底部附件入口增加「自动保存草稿」状态提示；共享记录仍保持双方独立视角。
- 「我们」页封面增加纪念日文案和纪念日信息卡，卡片点击进入原有纪念日编辑流程；名字、头像、主题选择保持原逻辑。

## 另一台 Android 机器的验收清单

请在同一构建版本上分别截取 390×844（或实际设备等比尺寸）图片，与以下参考图逐屏对比：

1. `home-timeline.png`：封面高度、标题层级、日期分组、节点线、底部凸起主操作。
2. `personal-entry-editor.png`：顶部时间、我的/共同切换、正文留白、附件工具栏和草稿状态。
3. `shared-entry-editor.png`：双方身份块、只读对方视角、发布入口。
4. `shared-album.png`：筛选态、三列媒体、视频入口、返回原记录。
5. `city-map.png`：城市快照按钮、节点路线、故事卡和无定位轨迹承诺。
6. `couple-profile.png`：封面文案、头像/名字、纪念日卡、主题和数据工具入口。

### 需要回传的证据

- 每屏一张完整截图（包含系统导航栏）。
- 空数据和至少一条真实数据各一张：时光、相册、地图至少覆盖这两种状态。
- 记录一条个人记录、切换到共同记录、打开相册媒体、保存城市快照、修改纪念日后，回到首页确认入口和返回路径均可用。
- 若与参考图存在偏差，按“布局 → 色彩 → 字体 → 间距 → 图标”顺序记录，不以“能启动”代替视觉验收。
