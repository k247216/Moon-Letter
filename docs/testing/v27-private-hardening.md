# V27 私有公网候选：保持现有初版，不提前上线

本轮只修改和验证本地源码。现网仍以用户已验证的 V25/Flyway13 为准；未安装新 APK、未恢复 USB、未启动公网。备案仍需按既定部署约定核实，不能把本地测试当作跨省验收。

## 候选内容

- Keystore 失败时禁止新令牌明文降级；读取失败保留身份、记录和原偏好，阻止新建空间。旧明文仅在成功重新加密落盘后才可使用。
- 原件上传先鉴权，分块校验后写入；已 READY 的相同原件允许丢 ACK 重试，不覆盖。操作ID不能跨成员/空间复用。OSS不再给客户端签发可覆盖原件的PUT URL，原件经后端验证后以文件流写入OSS，兼容原APK的 `local://` 上传协议提示；这是传输提示，不是改成手机本地存储。原件下载流式；标准 S3 checksum 的 Base64 转为已有 HEX 格式。
- 后端转发上传会占用ECS带宽/临时磁盘；不承诺OSS直传的性能。已签发的旧PUT链接不会立即失效，升级后等待原15分钟有效期结束再验收不可覆盖约束；RAM权限仍须保持最小化。
- SDK上传显式禁用 `aws-chunked` 并关闭非必需自动CRC尾部，保留应用自身完整SHA256验证；真实SDK本地HTTP捕获做回归。依据[阿里云OSS兼容说明](https://www.alibabacloud.com/help/en/oss/developer-reference/use-aws-sdks-to-access-oss)和[AWS校验配置](https://docs.aws.amazon.com/sdk-for-java/latest/developer-guide/s3-checksums.html)。原.env端点不自动改写，生产端点与真实写入仍须用更新后的探针核实。
- 敏感 POST 同源地址共享 10 次/分钟、全局 60 次/分钟，忽略可伪造的 Forwarded 头；通过反向代理时两人共享来源预算。普通同步不计入该预算。
- 新视频票据暂限 32 MiB、音频 16 MiB、图片 64 MiB；历史大原件不删除，流式下载保留旧资源兼容。旧 APK 在新后端上选超限文件会失败，不能把这种情况解释为已上传。
- 候选客户端同步收紧视频导入/录音确认边界；导入分块复制，超限不进入待上传队列，仅清理此次导入临时文件，不删除旧照片或录音。
- 文字同步、记录媒体和独立相册分开调度；记录/相册原件使用文件流。列表预览优先，全屏先预览再高清，保存仍使用原件；不修改自然比例拼图。
- `check-private-health.sh` 只读检查内部健康、资源、私有端口、备份 timer/最近恢复报告、服务端未就绪媒体和错误行数量。不输出 .env、令牌、媒体链接或正文；不会部署或修复。

## 运维执行顺序

1. 不先更新 APK。候选包完成回归和审查后，再由负责人更新私有后端；更新前保存 JAR 的 SHA256、旧包和当前配置，并生成且独立恢复数据库备份。
2. 本轮没有新增数据库迁移，预期仍是 V13；更新后必须实际核对。若以后含新迁移，旧 JAR 能否运行不能凭启动成功判断；不得通过还原旧数据库覆盖期间新增记录。
3. 只读巡检：`sh /opt/moonletter/check-private-health.sh`。该脚本未自动安装到 ECS，需要随经核验的运维包上传。非零退出代表需处理，不能改成忽略失败；没有实现手机主动告警。
4. 自动备份第一轮仍需真实服务日志与最新恢复报告，不能用 `timer active` 替代执行成功。现有 30 份上限会明确失败，需提前把已核验副本归档异机；不自动删除备份。
5. 数据库副本与 SHA256/manifest/fingerprints/restore-report 一并复制到另一台设备，再校验并恢复。不要把私有 .env 或密钥贴进对话。相同 ECS 上的副本不算异机备份。
6. OSS 原件单独保护：先列清图片/音频/视频对象和引用，再确定版本保护或独立复制、费用和恢复方法。数据库恢复不恢复 OSS 原件。此项尚未实际开启或验证，不宣称已完成。
7. 正式签名私钥异机恢复、原测试签名与正式签名的保留内容迁移未验证，不卸载重装替代。当前只做源码回归，真正 AndroidKeyStore 和覆盖安装必须留在设备验收门槛。
8. 备案条件核实后才执行既有 HTTPS 激活脚本：域名/受信任证书/续期和 80、443入口；8080、5432继续不暴露。随后覆盖安装相同签名候选、保留身份迁移地址，按公网验收表测试不同运营商/不同省份、无 USB 无隧道。

## 必须实测的同步场景

A 上传大视频期间 B 发文字；A 及时拉到文字。分别验证相册新增/删除、语音再次播放、视频、离线队列、重启恢复、双方身份、缓存原图保存。记录文本/预览/原件的实际延迟与失败，不承诺未实测的后台即时推送。

地图进程缓存、标签精细优化暂列后续性能批次；先测真实公网再决定瓦片源/CDN，不引入新付费服务。
