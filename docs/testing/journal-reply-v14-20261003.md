# V14：手账时间轴与评论输入体验

## 设计依据与范围

按 Product Design audit 技能先截图，再对照 `docs/design/reference/home-timeline.png` 校准。沿用暖纸、珊瑚/鼠尾草色、缝线和现有字体，不引入新的装饰体系、虚构互动数量或统计看板。

1. 日期从普通列表标题调整为手账章节，保留短下划线；不展示条数统计。
2. 图文记录正文与拍立得顶部对齐，左右交替；正文有淡纸色承托，减少图片与文字割裂。大字体/窄屏仍使用纵向布局。
3. 作者与时间形成稳定行，长名称省略，记录间用短虚线收尾，不再使用整行列表分割线。
4. 评论先完成本地持久化，再释放发送状态并清空已发送草稿；网络同步独立进行。网络失败不把已保存的评论误报为本地保存失败，期间新输入不会被清空。
5. 键盘避让由详情页 Scaffold 处理，输入栏仅处理导航栏；主 Activity 显式 adjustResize。

## 验证与限制

- 时间轴 JVM：22 项通过，包括本地保存后网络仍挂起时允许继续输入，以及同步失败不丢草稿/误报。
- 时间轴原生界面：23 项通过，覆盖图文交替、顶部对齐、大字体、详情和日期布局。
- 应用 JVM：69 项通过，包括双设备相册、图片和评论链路。
- 模拟器原生：评论键盘 1 项、图片缩放/系统边缘/导航对齐 6 项通过。发送前后字段底部到键盘顶部均约 22.1dp（含输入栏内间距），收起键盘后无键盘高度残留。
- 模拟器此前未复现用户说的大空白，因此这属于避让方式修正与回归验证，不能称为已复现并彻底修复所有输入法。
- 已连接实体手机覆盖安装 V14，无卸载、清库、重新配对。实体测试 Activity 未进入前台、IME 未出现；停止挂起测试，实际该机输入法仍待用户验收。
- 备案身份、正式签名和 ECS 公网配置均未改动；本轮不代表公网 HTTPS 已接通。
