## 首条真实记录闭环

### A 机：个人记录

- [ ] 从旧包覆盖安装新 APK，确认已有 Room 记录仍在。
- [ ] 首次设置能先填写名称、选头像；跳过照片为名称首字，不因成员顺序默认性别；后续可修改。
- [ ] 首次进入首页能看到紧凑城市月色封面、独立正文排版、缝线时间轴、五个对齐的底栏入口。
- [ ] 点击 `＋记录`，写入标题/正文和具体时间。
- [ ] 点击 `完成` 后，记录持久保存；首页/编辑器不显露队列状态，不能把本机保存冒充为对端可见。
- [ ] 返回时间轴，整张纸卡可点击进入详情；详情显示完整正文、作者和时间。
- [ ] 断网后重启 App，记录仍可打开；记录不重复。

### B 机：同步与回应

- [ ] B 机使用一次性配对码进入同一空间，显示真实双方称呼。
- [ ] 恢复网络后 B 机前台同步，能看到 A 的作者、时间、完整正文。
- [ ] B 机从详情发送一条回应；A 机能看到回应作者和时间。
- [ ] A 机追加一条离线记录，恢复网络后只出现一条，不产生重复卡片。
