## 1. 绑定与身份（先做这一步，否则后面全是脏结果）

- [ ] **1.1 第一位找回自己的位置**（走 A 起点）：「我是第一位」→ 地址、你的称呼、初始化密钥 → 初始化。应该看到：进了「我们」页，且**伴侣没有被挤掉**、空间里仍是原来那个人。失败长这样：新建了一个成员、或者提示「这个空间里已经没有可以找回的成员了」。
- [ ] **1.2 配对码把另一台接进来**：「我们」页 →「换手机或重新配对」→「生成配对码」→ 把码发给另一台 → 它选「我是伴侣」→ 粘贴 → 配对加入。应该看到：另一台进了同一个空间。
- [ ] **1.3 配对码是一次性的**：把同一个码再粘一次。应该看到：**「配对码已用过或已过期：请在另一台手机的『我们』里重新生成一个」**，而不是进去了第三个成员。
- [ ] **1.4 取个名字**：两台都在「我们」页点「取个名字」，各填自己的称呼并保存。应该看到：**两台手机上都立刻换成新名字**，包括对方那台。这条没做完，别往下写任何内容——她第一眼不能是「未命名」。
- [ ] **1.5 名字记得住**：杀掉应用再打开，名字还在。（再往后可顺手验：改过一次之后，重装那台重新绑定时填的旧名字**不会**覆盖掉她后来改的名字。）

## 2. 写与发布（产品的核心动作，也是唯一需要计时的地方）

- [ ] **2.1 记录成本计时（H1，必须写数字）**：从**解锁手机**开始掐表，到那条记录在自己时间线上出现为止。记下**秒数**和**点了几下**。目标 ≤10 秒、≤4 次交互。
  - 你的实测：`＿＿ 秒 / ＿＿ 次交互`（两台各测一次：`＿＿ 秒 / ＿＿ 次`）
  - 觉得慢就当场写下卡在哪一步（找入口？选类型？等转圈？），这就是下一轮要修的东西。
- [ ] **2.2 对端自己冒出来**：A 发一条，B **什么都不点**（不切页、不手动刷新）。应该看到：几秒内那条自己出现在 B 的时间线上。这条如果不动，就是同步链断了，后面的验证都别做，先回来告诉我。
- [ ] **2.3 图片真的在**：写一条带图记录并发布。应该看到：对端**看到那张图**（不是「[图片]」文字、不是空白框）；作者自己那台不会重新下载一遍。
- [ ] **2.4 回应看得见**：在对方那条**已发布**记录里回一句。应该看到：对方那台看到这句，署名是你的名字。
- [ ] **2.5 未寄出的记录不给人假象**：只写不发布（或断网时写完）。应该看到：这条带「未寄出」标记，且**对端完全看不到它**；详情页底部写明「寄出之后，TA 的回应才会落到这一页」，输入框不会让你白白写一句发不出去的回应。
- [ ] **2.6 共同记录各写各的**：建一条共同记录，两人各自补自己的部分。应该看到：两部分都在，作者显示正确；**你去改对方那一段**应该被拒绝（提示失败），而不是"看起来改成功了"然后悄悄变回去。
- [ ] **2.7 草稿不会被覆盖**：个人稿写一半 → 切去写共同稿 → 再切回来。应该看到：两份稿子各自还在，没互相吃掉。

## 3. 断网、重启与顺序（可靠性）

- [ ] **3.1 飞行模式写两条，恢复后按顺序到**（E2）：开飞行模式，连写两条并发布；关掉飞行模式，什么都不点。应该看到：两条**都**出现在对端，且**顺序和你写的顺序一致**（第二条不会跑到第一条前面）。
- [ ] **3.2 服务端不可用时界面不崩**：把电脑上的服务端进程停掉（告诉我，或你自己停），在手机上写一条并发布。应该看到：应用**不闪退**，那条显示「未寄出」；服务端回来后它自己补发成功。
- [ ] **3.3 杀进程不丢**：写一条到一半（没发布）→ 从最近任务里划掉应用 → 重新打开。应该看到：那半条还在，能接着写完。
- [ ] **3.4 重装后旧的那台进不来**（可选，走 A 起点时顺带就验了）：一台重新绑定之后，另一台如果还留着**旧**令牌去同步，应该失败并要求重新配对，而不是继续写进去。

## 4. 情感钩子（这两条是 JVM 上验过规则、但只有真机能证明"到点真的会响"）

- [ ] **4.1 对方写了新的**：B 发布一条，A 在本机同步完成时收到**一次**通知。应该看到：标题「TA 写了一条新的」、正文「点开看看」——**不含对方写的正文、不含标题、不含条数**；点它直达那条记录。A 自己写的、以及没发布的草稿，都**不该**触发通知。（系统设置里这条通道叫「对方写了新的」。）
- [ ] **4.2 关掉就真的安静**：在「回看与通知」里把它关掉，再让 B 发一条。应该看到：A 完全收不到，且重新打开后**不会**把之前攒的一次性全吐出来。
- [ ] **4.3 每周回看到点**：把回看的星期/时间改到**两三分钟后**，等它触发。应该看到：通知是「很久以前的一条 / 点开看看那天的你们」，点开就是那条**明显更早**的记录。（通道名「每周回看」。）
  - 如果你们的记录全是这几天的：应该**什么都不发**（这是设计，不是坏了）。想看到内容，需要先有一条 8 天以上的记录——真机做不到就先记「跳过路径正确」。
  - WorkManager 不保证精确到秒，晚几分钟算正常，**收不到**才算问题。
- [ ] **4.4 Android 13+ 的通知权限**：第一次进「回看与通知」时应该弹一次系统授权。拒掉之后应用不该反复骚扰；通知就是不再出现，页面本身仍可用。

## 5. 呈现毛刺（看到就是 bug，当场截图）

- [ ] **5.1 没有遮挡**：时间线最后一行、详情页的返回按钮和输入框，都不被底栏或状态栏吃掉；键盘弹起时输入框仍然看得见。
- [ ] **5.2 时间线可读**：正文是正文不是标题占位；日期按你写的那条的时间显示；没有测试期的爱心/占位假图这类残留。
- [ ] **5.3 点进去能回来**：时间线 → 详情 → 返回，列表位置不奇怪跳动。

## 6. 红线自查（这条不需要操作，只需要你在用的过程中留意）
