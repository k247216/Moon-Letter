# V22 城市回忆地图

## 产品边界

地图仍为主界面，摘要和城市回忆在下方，不改为统计仪表盘。
城市点只说明“有故事”，不推断实际到访、同行、旅行顺序或里程。
本轮不新增仅本机的“去过”状态；明确到访标记须与未来服务端模型一起实现。

## 已实现

- 按服务地址和情侣空间保存上次浏览城市；没有浏览历史时用最新带真实城市的记录，完全无记录时全国视图。
- 查看全部足迹重新框选全部故事城市；异步到达新城市时更新取景，同城市新增记录不反复重置用户视角。
- 普通点、暖色故事点、选中点三层样式；全国/区域/地级市逐层显示，标签避让。
- 城市、省级地区、记录总数按真实记录去重；无法匹配城市目录的地名不冒充城市。
- 每座城市首次/最近回忆日期；随机翻城优先避免当前城。
- 总览回忆卡包含代表照片（存在时）、城市、记录数、日期范围；选中城市保留手账记录及原详情入口。
- 离线图缓存标签测量；街道图更新样式和内容，复用已有标记，不反复重建全部标记。
