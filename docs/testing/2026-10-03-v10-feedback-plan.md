# V10 双机反馈修复

用户已授权本轮修复并要求连续推进。先完成局域网双机反馈，再推进大陆跨省云部署与独立相册共享；正式云端采购/凭据按已有阿里云方案沟通。

根因与修复：

1. 接收端只在启动/回前台/手动刷新拉取，发送依赖 WorkManager；增加前台生命周期内 3 秒周期拉取、发送直接同步，串行化同步循环，发送重试不再阻断接收。
2. 头像只保存在本机 URI；上传经过既有媒体接口并更新自己的 avatarAssetId，对端读资料时下载本机缓存，页面监听偏好即时刷新。
3. 语音只认 localPath，服务端快照替换块 payload 会丢失本机路径；同块同资产保留当前手机原文件路径，远端音频下载到持久缓存、进入页面自动准备、失败可重试。
4. 测试通知收拢到「我们→设置」一个入口；移除纪念日、胶囊重复测试和两分钟测试捷径。
5. 日期和提醒时间用系统选择器；倒计时在「我们」页直接展示，远端纪念日更新进入本机偏好并即时刷新。
6. 共同记录使用双署名、两位执笔状态、另一半留白邀请、原文只读和自己的可编辑分区，不伪造伴侣内容。

验证重点：同步重试仍能拉取、快照不丢本机音频、照片/头像真实服务双端读写、原生音频首次下载及退出页面后离线回放、日期选择和单一通知入口、共同记录视觉。

云端阶段尚不在本 APK 中宣称完成：独立相册共享、推送/长连接、跨省 HTTPS 与 ECS/OSS 部署需继续实现和实体网络验收。
