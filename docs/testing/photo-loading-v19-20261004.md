# V19 相册照片等待状态

修复用户反馈：云端照片刚进入相册、原图尚未下载时，短暂出现“照片无法读取”，稍后才恢复显示。

## 根因与修复

`AlbumCloudSync` 先合并元数据，随后下载原图。成功落盘后更新 `importedAtEpochMillis`。此前 `AlbumLocalPhoto` 在文件缺失时解码得到 null，立即把正常等待视为读取失败。

现在区分：

- 解码正在进行：小型进度指示与“加载中…”。
- 有云端 assetId、本机文件尚未落盘：继续显示“加载中…”，不显示读取失败。后台原有同步及重试机制继续运行；文件提交后依据数据库更新自动重读，包括已经打开的全屏查看。
- 本机文件存在但无法解码，或无云端关联且本机文件丢失：保留“照片无法读取”；全屏查看保留重试。

本轮没有新增网络错误码或逐文件下载进度追踪：断网导致云端缓存未到达时仍为等待加载，不宣称正在实际传输。没有改变已验收的 V18 自然比例拼图或 V17 相册集封面；未改数据库、云端接口、原始照片、配对或公网 HTTPS。
